# Лонгрид «Вы бы купили постиранный свитер?» — Важные вещи

Интерактивный лонгрид: обложка, вступление, тест из шести вопросов, шкала следа, честный блок о науке, финал, подписка на лист ожидания и источники. Ответ в тесте спрятан за шторкой: на компьютере она поднимается после выбора, на телефоне — пока листаешь вниз к рамке.

## Как открыть

Дважды кликнуть по `index.html`. Интернет не нужен: шрифты лежат в папке проекта.

## Что где лежит

```
index.html              — вся страница: тексты всех блоков, кроме теста
css/
  fonts.css             — подключение шрифтов Forum и Manrope
  base.css              — цвета, кнопки, рамка, шторка, заглушки фото
  quiz.css              — тест
  sections.css          — остальные блоки лонгрида
js/
  questions.js          — тексты теста: вопросы, варианты, ответы, результаты
  quiz.js               — логика теста, шкалы и шторки
  site.js               — форма подписки
assets/
  fonts/                — файлы шрифтов и их лицензии
  icons/                — звёздочки (золотая и тёмная для ползунка)
  images/frame.png      — золотая рамка
  images/curtain.jpg    — шторка
  images/photos/        — сюда класть свои фото
```

## Как работает тест

- Шкала сверху — это навигация. Можно вернуться к любому вопросу, до которого уже дошли: выбранный ответ подсвечен, шторка открыта, кнопка «ответить заново» работает.
- Сегменты: светлый — вы здесь, приглушённый — ответ уже открыт, серый — ещё нет.
- Звезда в конце шкалы ведёт к результату. Она загорается, когда открыты ответы на все шесть вопросов.
- «Показать ответ без выбора» — для тех, кто хочет просто почитать. Так текст лонгрида доступен целиком, даже без ответов.

## Как вставить фото

### В блоках страницы (index.html)

Заглушки выглядят так, рядом стоит комментарий `<!-- Фото: … -->`:

```html
<div class="photo photo--fill">
  <span class="photo__label">Фото: шерстяной свитер на вешалке с бумажной биркой</span>
</div>
```

Положите файл в `assets/images/photos/` и добавьте одну строку с картинкой внутрь блока:

```html
<div class="photo photo--fill">
  <img src="assets/images/photos/sweater.jpg" alt="Шерстяной свитер на вешалке с бумажной биркой">
  <span class="photo__label">Фото: шерстяной свитер на вешалке с бумажной биркой</span>
</div>
```

Картинка сама закроет заглушку и обрежется по размеру рамки.

| Где | Пропорции |
|---|---|
| Обложка, свитер | 4:5 (например, 1200×1500) |
| Гитара, рисунок древесины | 4:3 |
| Финал, паспорт | 3:4 на компьютере, 4:3 на телефоне — держите главное в центре |

### В тесте (js/questions.js)

| Где | Что в коде | Пропорции |
|---|---|---|
| Вопрос 3, «Так было всегда» | `photo` внутри `extra` | 3:4 на компьютере, 4:3 на телефоне |
| Вопрос 5, «Фото с автографом» | `photo` у варианта `autograph` | 4:3 |
| Вопрос 5, «Шарф» | `photo` у варианта `scarf` | 4:3 |
| Результат, карточки для сторис | `story` у каждого профиля | 9:16 (1080×1920) |

Впишите путь в `src`:

```js
photo: { src: 'assets/images/photos/scarf.jpg', alt: 'Шерстяной шарф в клетку' }
```

В `alt` напишите, что на фото: это читают незрячие пользователи. Имена файлов — латиницей, без пробелов. Вес — до 300 КБ на фото (сжать можно на squoosh.app). Когда у карточки для сторис появится `src`, под ней сама появится ссылка «скачать карточку».

## Как поменять тексты

- Тест — в `js/questions.js`, меняйте только то, что внутри кавычек. Апостроф ставьте типографский: ’. Неразрывные пробелы в тесте расставляются сами.
- Остальные блоки — в `index.html`. `&nbsp;` — это неразрывный пробел: он не даёт предлогу остаться в конце строки. Если переписываете фразу, ставьте его после коротких слов (в, с, и, на, не) и перед тире.

`points` у варианта — 1, если ответ совпал с тем, что нашли в исследованиях. По сумме выбирается результат: от 5 — «Хранитель следа», от 3 — «Ценитель историй», меньше — «Практик».

## Форма подписки

Сейчас форма проверяет почту и галочку «Мне есть 18 лет», показывает благодарность и поднимает шторку, но адрес никуда не уходит. Для настоящего запуска:

1. Подключите сервис рассылки или форм (например, Unisender или Google Forms) — место в коде отмечено в `js/site.js`.
2. Добавьте ссылку на политику обработки персональных данных: по закону 152-ФЗ без неё собирать почту нельзя.

## Как поменять рамку или шторку

Замените `assets/images/frame.png` или `assets/images/curtain.jpg` файлом с тем же именем. Если у новой рамки другая толщина, поправьте в `css/base.css` у `.frame` цифры в `border-width` и `border-image`.

## Как выложить в интернет

Через GitHub Pages: загрузить всё содержимое папки в репозиторий (так, чтобы `index.html` лежал в корне), в Settings → Pages выбрать ветку `main`. Через минуту сайт будет доступен по ссылке вида `имя.github.io/репозиторий`.
